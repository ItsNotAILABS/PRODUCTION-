# BLACKVECTOR VR

Original compact-wave WebXR FPS for Meta Quest 2 and desktop browsers.

## Included

- VR tracked firing and Touch controller models
- Snap turning and thumbstick locomotion
- Three selectable weapons
- Procedural humanoid enemies
- Compact indoor/outdoor combat arena
- Escalating waves
- Enterable armory zone and resupply economy
- Desktop mouse and keyboard fallback

## Run

```bash
npm install
npm run dev
```

## Validate

```bash
npm run certify
npm run build
```

Physical Quest 2 testing is still required before claiming stable headset frame rate or final controller alignment.
